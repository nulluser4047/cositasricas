# Cositas ricas

## English

A little corner to study, practice coding, and have fun with small experiments. I turn what I’m learning into drawings, animations, and programs I can run and tweak. Sometimes a whole animation starts with “What happens if I change this one number?” I keep the experiments here so I can come back to them after learning something new.


## Español

Un rinconcito para estudiar, practicar programación y divertirme haciendo pequeños experimentos. Acá convierto lo que voy aprendiendo en dibujitos, animaciones y programas que puedo ejecutar y retocar. A veces una animación entera empieza con un «¿qué pasa si le cambio este numerito?». Voy guardando esas pruebas para retomarlas cada vez que aprendo algo nuevo.


## Русский

Мой уголок, где я учусь программировать, экспериментирую и делаю то, что мне интересно. Я рисую, делаю анимации и пишу небольшие программы, чтобы сразу пробовать на практике то, чему научилась. Иногда целая анимация начинается с мысли «А что, если поменять вот это число?». Я сохраняю эти эксперименты, чтобы возвращаться к ним, когда узнаю что-то новое.
